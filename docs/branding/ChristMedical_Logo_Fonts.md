The closest matches are:

### CHRIST

A classic Roman serif style similar to:

- Trajan Pro (closest match)
- Cinzel
- Cormorant Garamond
- Forum

My recommendation would be **Cinzel** if you want a free font with the same dignified, mission-oriented feel.

### MEDICAL

- Montserrat
- Gotham
- Avenir Next

with increased letter spacing (tracking).
