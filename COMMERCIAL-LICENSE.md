## AGPL network-use obligation (plain English)

AGPL-3.0 requires that anyone who runs a **modified** version of this software
as a network service make the corresponding **modified source** available to
users of that service. Unmodified self-hosting still has AGPL obligations
(including source availability for the AGPL-covered work you convey); the
network clause is especially important when you ship modifications behind a
web or API interface.

Read the full text in [LICENSE](LICENSE). This paragraph is not a substitute
for the license.

Consider contacting the copyright holder for a commercial license if you want
to:
