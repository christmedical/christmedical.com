## How to use this doc

The 2016 deck is the most authoritative requirements artifact this project has: it came from interviewing the physicians who still lead the trips. This table maps every 2016 requirement to its current status so the review session with the doctors and the nurse reviewer is a checklist, not a meandering conversation.

Status legend:

- BUILT: implemented and matches the 2016 intent
- IN-FLIGHT: designed and/or being implemented now
- PENDING: doctor-validated, specified, not yet built
- GAP: built but missing something the 2016 deck (or clinical safety) requires
- DROPPED: intentionally removed; reason given
- OPEN-Q: an unresolved question the doctors/nurse should answer

## The unresolved doctor questions (p16) — review-session agenda

Bring this list to the two physicians and the nurse reviewer:

1. Which vitals/labs fields should show the up/down trend arrow: all, or a clinically-meaningful subset?
2. Does chronic illness need its own field, or does Past Medical History cover it adequately?
3. Is a free-text description enough for a Pap Smear treatment, or does it need structured fields?
4. What is Referral actually used for in the field? Free text, a facility list, or a follow-up hook?
5. Should Church be a dropdown (managed dictionary) rather than free text?
6. Confirm the columns for the Medications-for-Trip report.
7. (new) Do the three prescription statuses (refill / discontinued / did-not-dispense) match how pharmacy works on the ground?
8. (new) Confirm the named roles for the next trip (who is admin / coordinator / clinician).
9. (new, for the nurse) Where on the chart must Allergies appear to be safe at point of care? What other safety rails does an Epic-trained nurse expect that are missing here?

## Priority read for the build queue

From this analysis, the doctor-validated work still outstanding, in rough priority:

1. Surface Allergies + core clinical demographics on the chart (safety gap).
2. System-wide unambiguous date rule (safety gap).
3. Follow-up queue screen (high-value, doctor-specified, best phone feature).
4. Settings / dictionaries (unblocks coded diagnoses, formulary, locations).
5. Prescription copy-forward on new visit + full treatment-type set with icons.
6. Print suite (incl. the paper-backup blank form).
7. Trip lifecycle (open/close, one-at-a-time).

This list is doctor-validated demand, not invented scope. Everything here traces to a requirement the physicians gave in 2016.
